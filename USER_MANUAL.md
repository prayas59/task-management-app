# TaskFlow User Manual

## Introduction

Welcome to TaskFlow.

TaskFlow helps users organize, track, and manage daily tasks efficiently through a modern web interface.

---

# Getting Started

## Registration

1. Open the application.
2. Click **Sign Up**.
3. Enter:
   - Name
   - Email
   - Password

4. Click **Create Account**.

You will automatically be logged in.

---

## Login

1. Open the Login page.
2. Enter:
   - Email
   - Password

3. Click **Login**.

Your session remains active until logout.

---

# Dashboard Overview

The Dashboard displays:

- Task Statistics
- Task List
- Search Options
- Filters
- Sorting Controls
- Pagination Controls

---

# Creating a Task

1. Click **New Task**.
2. Enter:
   - Title
   - Description
   - Priority
   - Status
   - Due Date

3. (Optional) Upload an attachment.
4. Click **Create Task**.

The task appears instantly.

---

# Editing a Task

1. Locate the task.
2. Click **Edit**.
3. Modify required fields.
4. Click **Update Task**.

Changes are saved immediately.

---

# Deleting a Task

1. Locate the task.
2. Click **Delete**.
3. Confirm deletion.

The task is permanently removed.

---

# Task Statuses

| Status      | Meaning                        |
| ----------- | ------------------------------ |
| TODO        | Task not started               |
| IN_PROGRESS | Task currently being worked on |
| COMPLETED   | Task finished                  |

---

# Priority Levels

| Priority | Meaning                      |
| -------- | ---------------------------- |
| LOW      | Low urgency                  |
| MEDIUM   | Normal importance            |
| HIGH     | Requires immediate attention |

---

# Search Tasks

Use the search bar to locate tasks by title.

Results update automatically.

---

# Filter Tasks

Filter by:

- TODO
- IN_PROGRESS
- COMPLETED

---

# Sort Tasks

Available sorting options:

- Created Date
- Due Date
- Priority

---

# Activity Log

Each task contains an Activity button.

Activity Log tracks:

- Task Creation
- Task Deletion
- Status Changes
- Priority Changes

Activity updates appear in real-time.

---

# File Attachments

Users may upload:

- Images
- PDFs
- Documents

Attachments can be viewed directly from the task card.

---

# Real-Time Updates

Changes made from another browser or device appear automatically without refreshing.

Examples:

- New task created
- Task updated
- Task deleted
- Activity log updated

---

# Dark Mode

Use the theme toggle button to switch between:

- Light Theme
- Dark Theme

Your preference is saved automatically.

---

# Admin Features

Administrators can:

- View all users
- View all tasks
- Search across users
- Filter all tasks
- Monitor task activity

---

# Logout

Click Logout from the navigation menu.

Your session will be terminated securely.

---

# Troubleshooting

## Cannot Login

Verify:

- Correct Email
- Correct Password

---

## Attachment Not Visible

Refresh the task list.

If issue persists, upload again.

---

## Real-Time Updates Not Working

Verify:

- Internet connection
- Backend service availability
